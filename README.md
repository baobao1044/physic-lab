# ⚛️ Physic Lab

**A modern physics & chemistry sandbox simulation — made by baobg and Ryan**

> Built on top of [Sandboxels](https://sandboxels.r74n.com/) with a completely redesigned UI and additional science mods.

## 🎮 Play Now

👉 **[Play Physic Lab](https://baobao1044.github.io/physic-lab/)**

## ✨ Features

- 🧪 **Chemistry Mod** — Hundreds of chemical elements, compounds, reactions (acids, bases, gases, metals...)
- 🧬 **Biology Mod** — Living organisms, cells, organs, nutrition & oxygen systems
- 🎨 **Modern Dark Glassmorphic UI** — Premium lab-style interface with smooth animations
- 🔬 **High-Resolution Particles** — Optimized canvas rendering with anti-aliasing
- 🔍 **Quick Search** — Press `/` to instantly find any element
- 📱 **Responsive Design** — Works on desktop and mobile

## 🛠️ Tech Stack

- Vanilla JavaScript (no frameworks)
- HTML5 Canvas for particle simulation
- CSS3 with Glassmorphism design
- Google Fonts (Plus Jakarta Sans + JetBrains Mono)

## 📦 Local Development

```bash
# Clone the repo
git clone https://github.com/<your-username>/physic-lab.git
cd physic-lab

# Start a local server
python -m http.server 8000
# or
npx serve .
```

Then open `http://localhost:8000`
